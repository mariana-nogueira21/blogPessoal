# 📝 Blog Pessoal — Backend Java

Este repositório contém o backend do **Blog Pessoal**, desenvolvido em **Java** utilizando **Spring Boot**. Ele é responsável por gerenciar os dados do blog, como postagens, usuários e categorias, oferecendo uma API REST para integração com o frontend.

## ⚙️ Tecnologias utilizadas

- Java 11+
- Spring Boot
- Maven
- JPA / Hibernate
- MySQL (ou outro banco relacional)
- Spring Security (opcional)

## 📁 Estrutura do projeto

- `src/main/java`: código-fonte da aplicação
- `src/main/resources`: configurações e arquivos estáticos
- `pom.xml`: gerenciamento de dependências via Maven
- `mvnw`, `mvnw.cmd`: wrappers para execução do Maven
